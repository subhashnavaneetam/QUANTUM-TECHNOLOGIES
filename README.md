# QUANTUM-TECHNOLOGIES

**Web Architecture & Digital Engineering Studio** · Bengaluru, India

QUANTUM TECHNOLOGIES is a bespoke digital engineering studio that designs and builds web platforms, AI applications, and motion-rich digital brand experiences. This repository contains the studio's portfolio and marketing website.

**Live site:** https://subhash-productions.vercel.app/

## Services

1. **Full-Stack Web Architecture**: Next.js, React, TypeScript, and edge runtimes
2. **AI and Intelligence Interfaces**: LLM-powered apps with live streaming and side-by-side comparisons
3. **Bespoke Brand and Motion Experiences**: cinematic, GSAP-driven digital identities
4. **Cybersecurity and SaaS Architecture**: dashboards, client-side encryption, and PII masking

## Delivery Pipeline

**Discover** → **Design** → **Engineer** → **Deploy**

Architecture and UX scoping, then bespoke art direction, then Next.js and edge-compute engineering, then zero-downtime global production.

## Tech Stack

- **Framework:** Next.js 14 (App Router), React, TypeScript
- **Styling:** Tailwind CSS
- **Motion and 3D:** GSAP, Three.js (WebGL)
- **Runtime and hosting:** Edge runtimes, serverless infrastructure, Vercel

## Getting Started

> Adjust the commands below if your project uses a different package manager or script names.

**Prerequisites:** Node.js 18.17 or later, and npm (or pnpm / yarn).

```bash
# Clone the repository
git clone <your-repo-url>
cd <your-repo-folder>

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open http://localhost:3000 in your browser.

### Production build

```bash
npm run build
npm start
```

## Deployment

The site is deployed on [Vercel](https://vercel.com). Push to the main branch to trigger a production deployment, or import the repository into Vercel and it will detect Next.js automatically.
